# EAD Guide

## What is an EAD?

Employment Authorization Document (EAD) allows certain non-citizens to work legally in the US.

## Common EAD Categories

### OPT EAD
For F-1 students.

### STEM OPT EAD
For STEM graduates.

### H-4 EAD
For eligible H-4 dependents.

### Adjustment of Status EAD
Issued while Green Card application is pending.

## Recruiter Questions

1. What type of EAD do you have?
2. What is the expiration date?
3. Will you require sponsorship in the future?
