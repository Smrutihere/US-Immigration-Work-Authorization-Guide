# Work Authorization Guide

This guide helps US recruiters understand different work authorization categories and visa types.

## Categories

### US Citizen
- No sponsorship required
- Can work for any employer

### Green Card Holder
- Permanent work authorization
- No sponsorship required

### H-1B Visa
- Employer-sponsored work visa
- Can transfer between employers

### F-1 OPT
- Temporary work authorization for students
- Typically valid for 12 months

### STEM OPT
- 24-month extension for eligible STEM graduates

### H-4 EAD
- Employment authorization for eligible H-4 dependents
